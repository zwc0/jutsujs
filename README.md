# Jutsu JS

Resources:
svgs for tests from https://heroicons.com/
Polyfill for browser compatibility: https://www.npmjs.com/package/@webcomponents/custom-elements

## Components

### [Downloader](./src/components/downloader.ts)

The downloader component is an anchor tag wrapper which tracks the status the download resource.

### [Mask](./src/components/mask.ts)

The mask component applies a mask around an input such as the parenthesis and dashes for a standard US phone number.

### [Pager](./src/components/pager.ts)

The pager component hides and shows child elements based on the current page index.

### [SVG](./src/components/svg.ts)

The SVG component fetches an SVG resource and injects it to allow application of page/element-specific styles such as colors.
